## Engine and tools

- Unity 6 (6000.6.3f1) with the Universal Render Pipeline, Input System and uGUI packages
- Python 3 with Pillow and NumPy (development only, `Tools/`)
- Inspired by Darkest Dungeon and Vampire Survivors
